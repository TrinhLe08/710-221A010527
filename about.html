Mục tiêu dự án

  • Thực hành kỹ năng lập trình JavaScript cơ bản
  • Áp dụng HTML5 semantic tags cho cấu trúc trang web
  • Sử dụng CSS3 cho styling và responsive design
  • Xây dựng các ứng dụng web tương tác với người dùng
  • Hiểu và áp dụng các kỹ thuật bảo mật cơ bản
  • Tối ưu hiệu suất và trải nghiệm người dùng

Công nghệ sử dụng

HTML5 CSS3 JavaScript ES6+ Flexbox CSS Grid LocalStorage API Font Awesome Icons Responsive Design

Tính năng nổi bật

  • Responsive Design: Hiển thị tốt trên mọi thiết bị từ mobile đến desktop
  • Semantic HTML: Sử dụng đúng các thẻ HTML5 semantic
  • Clean Code: Code được tổ chức rõ ràng, dễ bảo trì
  • Bảo mật: Xử lý input an toàn, chống XSS cơ bản
  • Hiệu suất: Tối ưu DOM manipulation và memory management
  • UX/UI: Giao diện thân thiện, feedback rõ ràng
